# RISE Simulator and Emulator WG

## About RISE

[RISE](https://riseproject.dev) is a collaborative, industry-led initiative under the Linux Foundation that accelerates open-source software development for the RISC-V architecture.

## Charter

This working group covers QEMU and SPIKE projects for RISC-V simulation and emulation. Our objectives are to:

- Help collaboration across companies to avoid duplication of work
- Accelerate RISC-V support in simulators and emulators
- Communicate on the readiness of the respective ecosystems

## Project Tracking

Work is tracked on our [project board](https://github.com/orgs/riseproject-dev/projects/19).
